# KidneyCancerPrediction

To start, first download the dataset from [https://portal.gdc.cancer.gov/projects/TCGA-KIRC](https://portal.gdc.cancer.gov/projects/TCGA-KIRC).

- Put the folder labeled `manifest-xxn3N2Qq630907925598003437` into the `raw_data` folder.
- From there, sequentially run the `ML_pipeline.ipynb`.
- Likewise, to train the random forest, run the `random_forest_baseline.ipynb`.
